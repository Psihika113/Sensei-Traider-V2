# SenseiTrader — контракт торгового сигнала (Signal)

## Назначение

`Signal` — это минимальный набор данных, который передаётся от "мозга" (LLM / аналитики / стратегий)
в сервис SenseiTrader. Сервис не принимает никаких решений сам по себе — он только:

1. Валидирует сигнал.
2. Пропускает его через RiskGate (риск-модель).
3. При одобрении — формирует заявку(и) и пишет всё в БД.

## Обязательные поля

Все поля ниже должны присутствовать в JSON-сигнале.

- `signal_id: str`  
  Уникальный идентификатор сигнала.  
  Примеры: `"sensei-20251208-001"`, `"sig_aapl_intraday_001"`.

- `ts_utc: str`  
  Время генерации сигнала в формате ISO8601 UTC.  
  Примеры: `"2025-12-08T14:45:00Z"`, `"2025-12-08T14:45:00+00:00"`.

- `symbol: str`  
  Тикер инструмента. Примеры: `"AAPL"`, `"NVDA"`, `"TSLA"`.

- `asset_class: str`  
  Класс актива. Для акций: `"stock"`.

- `side: str`  
  Направление сделки:  
  - `"BUY"` — покупка (лонг);  
  - `"SELL"` — продажа (шорт).

- `entry_type: str`  
  Тип входа. Допустимые значения (строчные латинские буквы):  
  - `"market"`  
  - `"limit"`  
  - `"stop"`  
  - `"stop_limit"`

- `entry: float`  
  Цена входа.

- `stop: float`  
  Стоп-уровень (цена, при которой позиция закрывается с убытком).

- `take: float`  
  Тейк-профит (цена, при которой позиция закрывается с прибылью).

- `p_win_raw: float`  
  Оценка вероятности успешного исхода сделки **до калибровки RiskGate**.  
  Диапазон: от `0.0` до `1.0`.  
  Пример: `0.87`.

- `risk_pct_equity_max: float`  
  Максимально допустимая доля капитала, попадающая под риск в этой сделке.  
  Пример: `0.005` = 0.5% от капитала.

- `snapshot_hash: str`  
  Строковый идентификатор рыночного снапшота, к которому относится сигнал.  
  Требование: длина не менее 8 символов.  
  Часто можно использовать `signal_id` или `"snap-" + signal_id`.

## Правила по ценам

Для сигналов на покупку (`side = "BUY"`):

- Должно выполняться: `stop < entry < take`.

Для сигналов на продажу (`side = "SELL"`):

- Должно выполняться: `take < entry < stop`.

## Пример валидного сигнала

```json
{
  "signal_id": "sensei-20251208-001",
  "ts_utc": "2025-12-08T14:45:00Z",
  "symbol": "AAPL",
  "asset_class": "stock",
  "side": "BUY",
  "entry_type": "limit",
  "entry": 200.0,
  "stop": 196.0,
  "take": 210.0,
  "p_win_raw": 0.87,
  "risk_pct_equity_max": 0.005,
  "snapshot_hash": "sensei-20251208-001"
}
